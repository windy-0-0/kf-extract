## 1. 目标（按优先级，做完 P0 就算交付）

### P0-a 任务历史（必须）
- 左侧或顶部列出**本进程内**跑过的任务：素材名 / 参数 / 状态 / 耗时 / 开始时间
- 点一条能**恢复它的结果视图**（不用重跑）
- 正在跑的任务在列表里有**明显的运行中视觉态**（红底或等价强提示）
- **只存内存，不落盘**。理由：GUI 是短生命周期进程，落盘会引入「上次崩溃留下僵尸任务」

### P0-b 输出目录可改（必须）
- 一个输入框 + 「浏览」不可做（纯 Web 无文件选择器），所以提供**"用默认/自定义"两个态**
- 自定义路径必须做**白名单校验**：只允许家目录或项目目录之下（后端已有这个校验，前端要给出**可读的报错**，不能只弹 HTTP 400）
- 记住上次选择（`localStorage` 即可）

### P0-c 图片 viewer（必须）
- 点任意拼图/单帧 → 全屏/浮层放大，支持 **Esc 关闭**、左右箭头切图
- 图上要能看出**这是第几张、时间戳多少**（拼图上已烧了字，viewer 里再显示一次索引）

### P1-a 进度条要"像在动"（应该）
- 现在只有百分比数字。29 分钟素材解码要 40 秒，纯数字看着像卡死。
- 要求：**解码阶段显示"已解码 N/M 帧"**（数据已有，见 `progress` 回调的 msg）
- 并且 **≥10 秒没有任何进度变化时，显示"仍在工作（已 N 秒未更新）"** ——
  不许让用户以为卡死（这是 R35「长静默必须自己喊出来」）

### P1-b 键盘操作（应该）
- `Enter` 在选素材/参数区 = 开始；`Esc` 关闭 viewer；`Ctrl/Cmd+Enter` 也触发开始
- 焦点可见（别把 `outline` 去掉）

### P2 可选（有时间再做，不要挤掉 P0）
- 参数预设（"粗看剧情 40 帧" / "细看 160 帧"）
- 结果里的 `static_segments` 警告做成可点击 → 跳到对应时间点的单帧

## 2. 硬约束（违反即返工）

1. **不许引入任何新依赖**。`http.server` + 原生 JS 是当前选型；**不许**上 React/Vue/构建工具/WebSocket 库。
2. **不许改后端安全语义**：
   - 只绑回环、token 校验、目录白名单、**没有任何删除端点**
   - 如果你新增端点，它必须**有自己的 token 校验**，且**不许**接受任意路径
3. **不许破坏已实测的四件事**：连点去重、停止 496ms 内响应、中断状态不谎报、已导出帧不丢。
   改动相关代码后**必须重跑对应验证**（见 §5）。
4. **单文件优先**。前端继续放在 `_INDEX_HTML` 里（可以用模板字符串拆函数，但别拆成需要打包的多文件）。
5. **中文界面**。文案要"说人话"：错误要说**根因 + 怎么修**，不要只说 "400 Bad Request"。

## 4. 验证要求（这是本任务书的核心，不是附录）

### 4.1 必须用真浏览器驱动，不许只 curl

`curl` 只能证明"接口返回 200"，**证明不了界面能用**。项目里已有可用的无头浏览器流程
（上次用的 puppeteer-core + 本机 Chrome）。要求每个 P0 功能都有一条**真实交互**验证：

- 任务历史：提交 2 个任务 → 断言列表里有 2 条 → 点第 1 条 → 断言结果视图切过去了
- 输出目录：填一个**非法路径**（如 `/etc/shots`）→ 断言界面上出现**可读的中文报错**（不是原始 JSON）
- viewer：点第 1 张拼图 → 断言浮层出现 → 按 Esc → 断言浮层消失 → 按 → 断言切到第 2 张

### 4.2 每一条新闸门都要证明它会红

**这是上次踩过的坑，必须照做**：写完测试后，**故意把被测代码改坏**，
确认测试**变红**，再改回来。

⚠️ **注入的"坏行为"必须与闸门判据同频**（血泪教训，见 DECISIONS D-051）：
- 闸门看「目录里有没有新条目」→ 注入必须**产生新条目**，
  `mkdir` 一个已存在的目录**不产生任何变化，本来就不该被抓到**
- 判断"闸门失效"之前，先证明**注入确实造成了可观测差异**

### 4.3 必须测的（照抄这几条，不要自己发明更弱的）

1. **连点 5 次只产生 1 个任务**（已有测试思路，改后端后必须重跑）
2. **停止响应 < 2 秒**（实测基准 496ms；不许因为改成线程池/队列而退化）
3. **中断不谎报**：`status` 必须是 `interrupted`，界面上**不许出现"完成"字样**
4. **`--probe` 不写文件**（已有测试 `test_probe_writes_no_files`，改动 CLI 后要跑）
5. **静态段警告必须显示**：跑 `eval/codecast.mp4 --k 20`，
   断言界面出现「连续静止」字样（这是本产品最重要的诚实性特征之一）

### 4.4 全量回归（交付前必跑，并把输出贴进报告）

```bash
for f in tests/kf/test_*.py; do echo "== $f"; python3 $f; done   # 现有 138 条必须全绿
```
