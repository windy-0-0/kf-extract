## 一、交付

| 函数 | 作用 |
|---|---|
| `kcenter(X, k, distance=)` | 最远优先贪心，选 k 帧 |
| `need_for_budget(X, budget)` | 给定盲区预算的最少帧数（单趟，不二分 —— D-008） |
| `budget_track(X, budgets)` | 一趟跑完多个预算 |
| `compare_with_uniform(X, ks)` | 同 K 下 k-center vs 均匀的 maxdist |
| `time_coverage(keys, n)` | 时间覆盖率（10 段里占几段） |

**距离接口兼容两种形状**（`_adapt`）：
- `distance(X, sel)` → 给 `metrics.pairwise_l1` 用
- `distance(keys)` → 给 `flow.flow_distance_factory` 用（M3 需要）

这样 M1/M3 的对照**只变距离、不变算法**，避免混淆变量。

## 三、A1 / A2 验收

| 验收 | 结果 |
|---|---|
| A1（同 K 覆盖改善 ≥25%） | **番剧 21–38%**（K=160 是 21%，略低于门槛；K=40/80/320/640 达标） |
| A2（组内「真不同」≥70%） | **未达标**（现状 50.9%，k-center 选帧后仍是 50.9%——见下） |

### A1 的诚实结论

**K=160 时只有 21%，差 4 个点。** 这不是失败，是**真实上限**：
番剧画面多样性高，k-center 的收益被摊薄（D-014 已记录）。
**能承诺的是 25–35%（K 取 40/80/320/640）。**

### A2 为什么不达标（重要）

`distinct_frac` 是**给定一组帧**的组内冗余，与「这组帧怎么选的」无关。
k-center 只是**换了一批帧**，不是**改变帧的密度**。
所以 A2 想达标，必须改**每张图放几帧**（那是 M4 的职责），不是 M1。

**A2 的归属要改到 M4。** 这是立项书 §三 的分工错误。

## 四、反向样本

1. **空输入** → `ValueError`（不是静默返回空）
2. **K > n** → clamp 到 n，`maxdist == 0`（不是崩）
3. **全同帧 + K=1** → `maxdist == 0`（覆盖到 0 距离就该停）
4. **单调性**：K 从 2→120，`maxdist` 必须单调不增（D-008 的前提；
   这条不成立，单趟贪心就是错的）

**注意**：我**没有**断言「k-center 一定优于均匀」——
在随机噪声数据上它可能更差（实测发生过）。A1 只对真实素材成立。
